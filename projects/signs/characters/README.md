## Production rule
For any new storyboard:
1. Lock the empty environment first.
2. Lock the character sheet.
3. Lock props/table dressing.
4. Generate start/end stills from those locks.
5. Only then animate clips.

If a generated still drifts from the identity or set lock, reject it rather than treating the drift as a new reference.
